# Kizashi 設計書：UI／UXデザイン方針

> 位置づけ：`docs/Kizashi 設計書 v1.md`の詳細版。画面デザイン・デザイントークンを集約する。
> Clipnote（`clipnote.paritto.dev`）のデザインシステム（claude.aiに近い、温かみのあるニュートラル基調＋shadcn/ui挙動レイヤー）を土台にしつつ、Kizashiのプロダクト性格（Threads投稿のAI生成・管理・予約投稿＝「成長・前向きな運用を後押しするツール」）に合わせてアクセントカラーをグリーン系に変更したもの。

---

## 1. デザインシステムの採用方針

Clipnoteと同様、画面の性質によってデザインシステムを使い分ける。

| 画面 | 採用方針 | 理由 |
| --- | --- | --- |
| ダッシュボード以下（Draft一覧・詳細、グループ管理、プロジェクト管理、アカウント連携設定、APIキー管理） | **shadcn/ui（挙動レイヤー）+ Tailwind CSS、テーマは2章のトークンで完全上書き** | フォーカストラップ・キーボード操作・ARIA属性等のアクセシブルな挙動を実装コストなしで得るため。既定の見た目（配色・角丸・フォント）はそのまま使わず、本書のデザイントークンで上書きする |
| ログイン画面 | **カスタム（Tailwind CSSでトンマナ設計）** | プロダクトへの入口であり、Kizashiの世界観（グリーン系アクセント）を最初に印象づける |

Draft生成は独立画面ではなくモーダル（`docs/Kizashi 設計書 v1.md` 7章）とする方針は変更しない。モーダル・ダイアログ類もダッシュボードと同じshadcn/uiベースで統一する。

### 1-1. デザインの雰囲気

Clipnoteと同じ「claude.aiに近い、温かみのあるニュートラル基調」を踏襲しつつ、アクセントカラーのみグリーン系に差し替える。「兆し（きざし）」の名の通り、Draftが投稿として育っていく過程を後押しするような、成長・前向きな印象を1色のアクセントで表現する。ダークモードはMVPでは対応しない（ライトモードのみ、Clipnoteと同方針）。

## 2. デザイントークン

Clipnoteのトークン構成（`docs/design-web.md` 3-2節）をベースに、アクセントカラーのみグリーン系へ変更する。背景・テキストの階調構造はニュートラル基調を維持するため、Clipnoteと同じ考え方（クリーム系の背景、濃淡4段のテキスト）を踏襲する。

| トークン | 値 | 用途 |
| --- | --- | --- |
| フォント（見出し・本文） | `Plus Jakarta Sans`（サンセリフ） | 見出し・本文とも統一。見出しは本文より太めのウェイトでコントラストをつける（Clipnoteと共通） |
| フォント（コード的表示） | `JetBrains Mono` | APIキー文字列・Draft本文の文字数表示など、等幅が望ましい箇所 |
| **アクセントカラー（メイン）** | **`#2F9E63`** | 主要なボタン・アクティブ状態・「予約済み」「公開済み」等のステータスバッジ（**Clipnoteのテラコッタ`#C1503A`から変更**） |
| **アクセントカラー（濃色バリアント）** | **`#25824F`** / **`#1B5E3A`** | ホバー状態、強調テキスト等 |
| **アクセントカラー（淡色バリアント）** | **`#C7E8D4`** | アクセントの背景敷き・淡いハイライト（Draftステータスバッジの背景等） |
| 背景色（クリーム系、明→暗） | `#FBF6F0` → `#F3E9DD` → `#F3E4DA` → `#F1E7DB` → `#E8DCD0` | ページ背景、カード背景、階層による濃淡の使い分け（Clipnoteと共通） |
| テキストカラー | `#2B2320`（濃）/ `#3D332C` / `#6B5D52` / `#8A7A6D`（淡） | 見出し・本文・補助テキストの階調（Clipnoteと共通） |
| 角丸 | 12px（小要素：バッジ・チップ等）〜32px（大きめのカード・ダイアログ）、丸ボタン・アバター等は`999px` | 要素のサイズ・重要度に応じて使い分け（Clipnoteと共通） |
| 影 | `0 10px 28px -18px rgba(43,35,32,0.18)`（通常のカード等、控えめ）／`0 6px 16px -8px rgba(47,158,99,0.5)`（アクセントカラーを使う要素の強調影） | 強いドロップシャドウは使わない方針を維持。強調影の色のみアクセントカラーに追従してグリーン系に変更 |

### 2-1. アクセントカラー選定の理由

- Clipnoteのテラコッタ系（`#C1503A`）はブランドの温かみを担う一方、Kizashiは「投稿の兆しを育てる」プロダクトであるため、成長・前向きさを想起させるグリーン系を採用する
- 背景のクリーム系・テキストの階調はClipnoteと共通のニュートラル基調を維持し、Parittoファミリーとしての一貫性（余白の広さ・角丸・シャドウの控えめさ）は保つ。差別化はアクセントカラー1色に限定する
- コントラスト比：`#2F9E63`は白背景・クリーム背景（`#FBF6F0`〜`#E8DCD0`）に対しWCAG AA相当のコントラストを確保できる明度に調整済み。ボタンテキストは白（`#FFFFFF`）を基本とする

## 3. アクセントカラーの適用箇所（Kizashi画面への割り当て）

`docs/Kizashi 設計書 v1.md` 7章の画面遷移をもとに、アクセントカラーを使う代表箇所を整理する。

| 画面・要素 | 適用 |
| --- | --- |
| ダッシュボードのアカウントスイッチャー（アクティブ状態） | アクセントカラー塗りつぶし |
| Draft一覧のステータスバッジ（`ready_to_publish` / `published`等） | 淡色バリアント背景＋濃色バリアントテキスト |
| Draft生成モーダルの「生成」ボタン | アクセントカラー塗りつぶし |
| Draft詳細の予約設定・実測実績グラフのハイライト系列 | アクセントカラー |
| グループ・プロジェクト管理の「＋新規作成」ボタン | アクセントカラー塗りつぶし |
| APIキー管理の有効なキー表示 | 淡色バリアント背景 |
